📋 INTRODUCTION

Document Type: Privacy Policy
Website: Gerivan Costa Portfolio
Purpose: Data Protection Information

Welcome to Gerivan Costa's portfolio website. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you visit our website. Please read this privacy policy carefully. If you do not agree with the terms of this privacy policy, please do not access the site.

⚖️ COMPLIANCE FRAMEWORK

Primary Law (BR): LGPD 13.709/2018
Primary Law (EU): GDPR 2016/679
Additional Standards: Marco Civil da Internet

This website operates in full compliance with Brazilian and European data protection regulations, implementing all required principles and safeguards for user privacy.

🇧🇷 BRAZILIAN LGPD COMPLIANCE

Law Number: 13.709/2018
Enforcement: ANPD (National Authority)
Principles: 10 Core Principles

Our data processing follows LGPD principles including purpose limitation, data minimization, transparency, security, and accountability. All data subjects have guaranteed rights under Brazilian law.

🇪🇺 EU GDPR COMPLIANCE

Regulation: EU 2016/679
Applicability: EU Visitors
Data Rights: 8 Fundamental Rights

For European Union visitors, we comply with GDPR requirements including lawfulness, fairness, transparency, purpose limitation, data minimization, accuracy, storage limitation, integrity, and confidentiality. Note that this site is hosted on GitHub Pages, operated by GitHub, Inc. (USA); any server log data referenced below may therefore be processed outside the EEA, subject to GitHub's own Data Protection Agreement and standard contractual clauses.

🔍 DATA COLLECTION

Forms/Registration: None
Cookies/Tracking: None
Analytics Tools: None
GitHub Pages Logs: IP, Browser, OS

As a static website, we implement a privacy-by-design approach. No active data collection mechanisms are deployed. GitHub Pages (hosting provider) may collect standard server logs for security and maintenance.

🔐 DATA SECURITY

Encryption: HTTPS (SSL/TLS)
Security Headers: CSP, X-Frame, X-Content
External Scripts: None
Tracking Protection: Full

Security measures include HTTPS encryption, a Content Security Policy that blocks all scripts and disallows this page from loading any embedded frames, MIME type validation, and a strict referrer policy. No external tracking or analytics scripts are loaded.

📁 DATA RETENTION

Active Collection: None
Retention Period: N/A
GitHub Logs: Subject to GitHub Policy

Since no personal data is actively collected, no retention periods apply. Any server logs maintained by GitHub Pages are governed by GitHub's privacy policy and standard retention practices.

👤 YOUR RIGHTS

Access: Right to Access
Rectification: Right to Correct
Deletion: Right to Erasure
Portability: Right to Data Portability

Under both LGPD and GDPR, you have comprehensive rights regarding your personal data. These include access, rectification, deletion, restriction of processing, data portability, objection to processing, and protection against automated decision-making.

👶 CHILDREN'S PRIVACY

Age Restriction (US): Under 13
Age Restriction (EU): Under 16
Data Collection: None

This website is not directed to children under 13 (United States) or 16 (European Union). We do not knowingly collect information from children. The content is technical and intended for professional audiences.
